# JobScout for Vercel

Personal job discovery, saved applications and daily email digests, with Ami’s navy/violet/mint portfolio styling.

**Start with [SETUP.md](SETUP.md)** for GitHub upload, Vercel deployment, Neon database connection, password protection and Resend email setup.

This is the native Next.js/Vercel edition. It does not require Cloudflare, Sites or a ChatGPT account. It contains no credentials. Email delivery requires your configured services and must be enabled in the app.
